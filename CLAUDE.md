## Architecture

This is a **TanStack Start** (SSR-enabled React framework) app using file-based routing.

**Key files:**
- `src/routes/__root.tsx` — Root layout: defines the HTML shell, global CSS, and mounts TanStack devtools
- `src/router.tsx` — Router factory (`getRouter`), registered globally via module augmentation
- `src/routeTree.gen.ts` — Auto-generated by TanStack Router from files in `src/routes/`; **do not edit manually**
- `src/routes/index.tsx` — Index route (`/`)

**Routing:** Add new pages by creating files under `src/routes/`. TanStack Router's Vite plugin auto-regenerates `routeTree.gen.ts`. Each route file exports a `Route` created with `createFileRoute('/<path>')`.

**Path aliases:** `#/*` and `@/*` both resolve to `src/*`.

**Styling:** Tailwind CSS v4 via the Vite plugin (`@tailwindcss/vite`). Global styles are in `src/styles.css`, loaded as a URL import in the root route's `head()`.

**TypeScript:** Strict mode with `noUnusedLocals`, `noUnusedParameters`, and `verbatimModuleSyntax`. Module resolution is `bundler`.

**ESLint:** Uses `@tanstack/eslint-config` as the base. Import cycle/order rules and some TS rules are disabled (see `eslint.config.js`).
